# Commandes

| Action | Commande par défaut |
| --- | --- |
| Déplacement | ZQSD, ou WASD avec la disposition QWERTY |
| Regarder et tirer | Souris et clic gauche |
| Lunette | Clic droit avec une arme de précision |
| Zoom de l’Eclipse Rail | Molette pendant la visée |
| Charger Nova Charge ou Stellar Lance | Maintenir le clic gauche, puis relâcher |
| Emplacements | 1–4 ou molette hors visée |
| Recharger | R |
| Sauter et sprinter | Espace et Maj |
| S’accroupir ou glisser en sprint | Ctrl |
| Activer le gadget | G |
| Inspecter l’arme | I |
| Interagir | E |
| Journal | Tab |
| Pause ou retour | Échap |

En solo, la pause suspend le temps de combat. En coop, elle ouvre le menu du pilote et le serveur continue la simulation. Les commandes de clavier se configurent dans **Paramètres → Clavier**. **Jeu et confort** règle la sensibilité de la lunette, le réticule, le recul, les flashes, l’oscillation et les chiffres de dégâts.

## Reproduire

```sh
python3 tools/release_version.py --tag v0.0.6-alpha
python3 tools/run_tests.py --suite all
python3 tools/run_tests.py --suite soak --soak-seconds 1200
```

Le scénario d’endurance utilise un profil isolé, les sept cartes, des matchs contre les bots, des changements de menus, et des notifications Android simulées. Le chronomètre est en temps réel. Les mesures de mémoire concernent le moteur. Le banc de rendu existant se lance avec `tests/benchmark.gd`, comme indiqué dans [V3_PERFORMANCE.md](V3_PERFORMANCE.md).

## Conditions de publication

Le paquet Android reste `com.riflearena.alpha`. Le build v0.0.5 utilisait un keystore de CI temporaire. La mise à jour Android exige la clé qui a signé cette APK. La chaîne de publication compare les deux certificats, installe la nouvelle APK par-dessus la précédente et attend la validation des deux téléchargements. Les artefacts de revue sont signés pour une installation de test.

Le tag attend les essais physiques et la validation de la signature. Les secrets et la variable de validation matérielle sont décrits dans [le README](../README.md).

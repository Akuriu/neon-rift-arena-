## Si la clé d’origine manque

Conserver l’Alpha installée et sa sauvegarde. La Preview possède son propre paquet Android et peut servir aux essais. Un changement du paquet stable doit accompagner une procédure explicite de transfert du profil et un nouveau certificat conservé durablement. La récupération du profil de l’ancienne application doit être testée sur le téléphone avant d’annoncer une migration disponible.

Le connecteur GitHub ne révèle pas les valeurs des secrets. Le workflow d’audit s’exécute dans GitHub Actions, compare uniquement les certificats publics et produit un rapport JSON sans clé ni mot de passe.

Les validations de signature, de mise à jour, de SHA-256 et d’essai matériel du workflow officiel sont conservées. La préparation de la v0.0.7 continue sur une branche séparée à partir de cette candidate.

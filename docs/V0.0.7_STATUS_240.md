# v0.0.7 — état des 240 étapes

Ce rapport décrit un point d’arrêt de développement et les préversions de contrôle. Il ne déclare pas les 240 étapes terminées. Les fonctions déjà présentes en v0.0.6 sont distinguées dans les preuves des ajouts v7. Les lignes « Terminée et testée » s’appuient sur la preuve indiquée. Les lignes bloquées précisent l’appareil ou la condition de publication manquante.
